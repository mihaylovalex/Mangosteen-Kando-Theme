# Mangosteen for Kando

A modern, minimalist, and highly customizable radial menu theme for [Kando](https://kando.menu/).

**Mangosteen** combines a clean, macOS-inspired aesthetic with smooth animations, dynamic interactions, and flexible customization. Designed to feel elegant, responsive, and unobtrusive in everyday use.

## ✨ Features

- **Smooth animations** — subtle scale and fade transitions when opening and closing the menu.
- **Dynamic hover effects** — sectors smoothly expand outward, highlight with an accent color, and adjust their icons.
- **Customizable circular background** — configure the background fill, outline, center, and soft shadows independently.
- **Transparent elements** — support for translucent colors with correctly composited inner borders.
- **Directional submenu indicator** — a triangular arrow pointing toward the parent menu.
- **Flexible positioning** — designed for both fixed and freely positioned menus, including Anchored Mode.
- **Adaptive sectors** — automatically adjust to different menu structures and item counts.
- **Extensive customization** — adjust colors, dimensions, icon sizes, spacing, and animation timings.

## 🎨 Customization

Mangosteen is designed to be easily customizable without modifying its underlying geometry.

- `theme.json5` — colors, opacity, and theme metadata.
- `theme.css` — dimensions, animations, icon sizes, borders, and visual effects.

Most visual properties are exposed as CSS variables for convenient adjustment.

## 📦 Installation

1. Download the latest release.
2. Extract the theme into your Kando themes directory.
3. Open Kando settings and select **Mangosteen**.
4. Enjoy your new radial menu!

For Windows, the custom themes directory is:

`%APPDATA%\kando\menu-themes\`
